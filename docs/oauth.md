# Gmail / Outlook 的 OAuth 登录

Google 和微软不允许应用内置共用的客户端 ID 给个人项目随便用，所以需要自己注册一个（免费，约 5 分钟，只做一次）。注册后把客户端 ID 填进“添加邮箱”对话框，之后在浏览器里点同意即可。令牌加密保存在本机，不经过任何第三方服务器。

密码 / 授权码登录仍然保留。已有的 Gmail 密码账户不受影响；用同一个邮箱走 OAuth 添加时，会原地升级该账户，别名等设置保留。

## Microsoft（Outlook / Hotmail / 工作或学校账户）

1. 打开 <https://portal.azure.com> → Microsoft Entra ID → 应用注册 → 新注册。个人账户也可以登录这里，无需订阅。
2. 名称随意；“受支持的账户类型”选 **任何组织目录中的账户和个人 Microsoft 账户**。
3. 重定向 URI：平台选 **移动和桌面应用程序**（或“公共客户端”），填 `http://localhost`。
4. 注册后，复制“应用程序（客户端）ID”。
5. 在“身份验证”页确认“允许公共客户端流”为是。
6. 无需创建密钥，也无需手动添加 API 权限（登录时会弹窗让你同意 IMAP 与发信权限）。

在 Light Mail 里：添加邮箱 → 服务商选 Outlook / Hotmail → 用 Microsoft 账号登录 → 填入客户端 ID。

## Google（Gmail）

1. 打开 <https://console.cloud.google.com>，新建一个项目。
2. API 和服务 → 库 → 启用 **Gmail API**。
3. API 和服务 → OAuth 权限请求画面：用户类型选 **外部**，填应用名称和你的邮箱；在“数据访问/范围”里添加 `https://mail.google.com/`。
4. **发布状态要点“发布应用”，切到“正式版”。** 停在“测试”状态时，授权每 7 天就会失效，需要重新登录。个人使用无需提交审核；登录时会看到“未经验证的应用”警告，点“高级 → 继续”即可。
5. API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID，应用类型选 **桌面应用**。
6. 复制客户端 ID 和客户端密钥（桌面应用的密钥不具保密性，Google 的设计就是如此）。

在 Light Mail 里：添加邮箱 → Gmail → 用 Google 账号登录 → 填入客户端 ID 和密钥。

## 登录失效怎么办

访问令牌约 1 小时自动刷新。长期授权被撤销、过期（Google 测试状态 7 天）或改了密码后会失效，侧栏会提示“登录失败”。到该邮箱的设置（齿轮）里点 **重新登录**。
