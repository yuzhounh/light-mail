## 使用与配置迁移

- 原生 Android 客户端，Android 11 / API 30 以上，应用 ID `com.yuzhounh.lightmail`；当前源码与安装状态见顶部。直接连接用户配置的 IMAP/SMTP 服务器，不依赖桌面代理或开发者服务器。
- 0.2.2 将缓存列表、搜索和未读过滤移到独立查询线程；连续搜索仅接受最新结果，保留对旧缓存邮件的搜索。后台补偿任务复用最近成功同步，仍保留服务退出后的兜底。
- 邮箱入口可以切换账户、收件箱、本地草稿及服务器文件夹。设置中可编辑别名、服务器、端口和授权码；邮箱菜单可调整账户顺序。
- 邮件列表按发件人/日期、主题、正文摘要三行显示，长按开始多选；支持已读/未读、星标、归档、垃圾邮件、移动与删除。永久删除和移到废纸篓需确认，跨账户移动会拒绝。
- 写邮件使用独立页面，发送和附件入口位于顶部。输入后约 250 毫秒保存本地草稿，离开页面时再次保存；草稿入口可恢复，发送成功或确认放弃后清除。附件复制到应用私有目录，单个最多 20 MB。
- 正文和列表保存在手机本地。首次同步先取最近 60 封的列表，并预取最近 10 封正文；“加载更早邮件”继续增加列表范围。未缓存的旧正文首次打开需要联网。后续检测到的新邮件自动缓存正文后再通知，不会因后台预取标为已读。
- 当前搜索仅覆盖本机已缓存的主题、发件人和摘要。转发目前包含文字引用，原邮件附件需要另行添加。尚未提供 OAuth、通讯录同步、桌面草稿/缓存迁移或手势滑动操作。

桌面迁移只导出邮箱地址、用户名、发件人名称、别名及 IMAP/SMTP 服务器配置，不导出密码。Windows 凭据不能直接作为 Android KeyStore 密文使用。手机填入授权码后自行同步服务器邮件，桌面未发送的本地草稿不会自动出现。

导入时在手机选择“从电脑导入配置”，再由 USB 调试连接转发手机回环端口 48765。电脑向 `/accounts` POST UTF-8 JSON `{ "accounts": [...] }`，手机确认后导入；已有账户按地址匹配并保留其手机密码。监听仅在回环接口临时开放，等待超时自动关闭。完成后关闭转发、退出导入监听，并清理私密的临时配置文件。配置文件不得进入源码或安装包。

## 外观

采用浅蓝到淡紫/暖白的渐变页头、近白内容区、白色账户卡片和浅色邮箱标记。取消常驻底部导航，由右上角圆形按钮进入整页的邮箱、草稿、文件夹和设置；返回后保留邮件列表位置。列表在顶部继续下拉即可刷新，上滑收起搜索框并缩小标题栏，下滑恢复；右侧导航入口始终保留。写信使用右下角 56dp 圆形笔图标按钮。全局字号收紧一档，邮件行间距相应缩小，但按钮触摸区域仍至少 48dp。主按钮为蓝底白字，次要按钮为浅蓝底，均有触摸波纹；图标使用统一 24 单位坐标和 1.8 单位圆头线条。

参考本地 LinkFlow Android 的圆角按钮、LightNote 的简洁排版以及 Soft Trace 的浅色卡片；移动邮箱导航参考 [Gmail 官方导航说明](https://support.google.com/mail/answer/18522?co=GENIE.Platform%3DAndroid&hl=en)。没有复制其他产品的品牌图标或素材。

## 存储与后台收信

账户授权码通过 Android KeyStore AES/GCM 加密保存；SQLite 和原始 MIME 邮件、草稿及附件位于应用私有目录。卸载或清除应用数据会删除本机内容，服务器邮件不受影响。应用关闭系统备份；本地草稿不是云端备份。

连接启用 TLS、服务器证书及主机名验证；非直连 TLS 的配置强制 STARTTLS。正文经过 HTML 清理，WebView 禁用 JavaScript 和文件访问，外部链接交给系统浏览器。远程图片会产生对图片服务器的请求。

“后台收信”开启时尝试以前台服务监听 IMAP IDLE，并显示持续通知。Android 15+ 对 `dataSync` 前台服务有六小时/24小时的系统预算；停止后退回约 15 分钟的系统调度检查，实际执行受省电、网络和厂商后台限制影响。强制停止后需重新打开。不能承诺全天即时到达；参见 [Android 官方限制](https://developer.android.com/develop/background-work/services/fgs/timeout)。新邮件通知需要系统通知权限。
